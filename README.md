## Anti-Caution Filter — Always Ask Yourself

```
1. Am I waiting for more data when 60% certainty is already enough to act?
2. Has the trading desk heard from me this week about what my team shipped?
3. Is my default response to a business question: defensive explanation or confident headline?
4. Am I protecting my team from visibility — or elevating them into it?
```

## Weekly Cadence Template

| Day | Action |
|---|---|
| **Monday** | Set 1 measurable team sprint goal — make it visible to a stakeholder |

| **Friday** | Run 1 SBI feedback conversation with a direct report |
